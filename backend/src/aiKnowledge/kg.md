<!-- q:html-what -->
HTML (HyperText Markup Language) — бул веб-барактардын түзүмүн түзүү үчүн колдонулуучу гипертексттик белгилөө тили.

HTML аркылуу төмөнкүлөрдү кошууга болот:
- Аталыштар.
- Текст.
- Сүрөттөр.
- Шилтемелер.
- Баскычтар.
- Формалар.

Мисал:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Менин биринчи сайтым</title>
</head>
<body>
    <h1>Салам, дүйнө!</h1>
    <p>Бул менин биринчи сайтым.</p>
</body>
</html>
```

**Корутунду:** HTML ар бир веб-сайттын негизин жана түзүмүн түзөт.

<!-- q:css-what -->
CSS (Cascading Style Sheets) — веб-барактардын тышкы көрүнүшү үчүн жооп берген стилдер тили.

CSS аркылуу төмөнкүлөрдү өзгөртүүгө болот:
- Тексттин жана фондун түсү.
- Арип өлчөмү.
- Элементтердин жайгашуусу.
- Блоктордун өлчөмдөрү.
- Анимациялар.
- Сайттын адаптивдүүлүгү.

Мисал:

```css
h1 {
    color: green;
    font-size: 32px;
    text-align: center;
}

body {
    background-color: #f0fff5;
}
```

**Корутунду:** HTML түзүмдү түзөт, ал эми CSS сайтты кооз жана ыңгайлуу кылат.

<!-- q:html-vs-css -->
HTML менен CSS ар башка милдеттерди аткарат, бирок бирге иштешет.

HTML сайттын түзүмү үчүн, CSS анын жасалгасы үчүн жооп берет.

HTML мисалы:

```html
<h1>Кош келиңиз!</h1>
```

CSS мисалы:

```css
h1 {
    color: blue;
    font-size: 30px;
}
```

HTML аталышты түзөт, ал эми CSS ага көк түс жана өлчөм берет.

**Корутунду:** Толук кандуу сайт түзүү үчүн эки тилди тең үйрөнүү маанилүү.

<!-- q:js-what -->
JavaScript — веб-сайттарга интерактивдүүлүк кошкон программалоо тили.

Ал төмөнкүлөргө мүмкүндүк берет:
- Иштеген баскычтарды түзүү.
- Формаларды текшерүү.
- Калькуляторлорду түзүү.
- Барактын мазмунун өзгөртүү.
- Оюндарды иштеп чыгуу.
- API менен иштөө.

Мисал:

```javascript
function sayHello() {
    alert("Салам! Кош келиңиз!");
}
```

```html
<button onclick="sayHello()">Мени бас</button>
```

Баскычты басканда билдирүү чыгат.

**Корутунду:** JavaScript сайттарды динамикалуу жана интерактивдүү кылат.

<!-- q:js-variable -->
Өзгөрмө — маалыматтарды сактоо үчүн аталышы бар орун.

JavaScript'те өзгөрмөлөрдү жарыялоонун үч негизги жолу бар: let, const жана var.

Мисал:

```javascript
let name = "Akinai";
const age = 20;

console.log(name);
console.log(age);
```

- let — өзгөрмөнүн маанисин өзгөртүүгө болот.
- const — башка маанини кайра ыйгарууга болбойт.
- var — өзгөрмөлөрдү жарыялоонун эски жолу.

**Корутунду:** Өзгөрмөлөр программада маалыматты сактоого жана колдонууга мүмкүндүк берет.

<!-- q:js-function -->
Функция — белгилүү бир тапшырманы аткарган код блогу. Аны бир нече жолу чакырууга болот.

Мисал:

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(5, 3));
```

Натыйжа:

```javascript
8
```

Функциялар төмөнкүлөргө жардам берет:
- Бирдей кодду кайталабоо.
- Программаны бөлүктөргө бөлүү.
- Иштеп чыгууну жеңилдетүү.
- Даяр логиканы кайра колдонуу.

**Корутунду:** Функциялар программалык кодду ыңгайлуу жана иреттүү кылат.

<!-- q:react-what -->
React — колдонуучу интерфейстерин түзүү үчүн JavaScript китепканасы.

Ал аркылуу төмөнкүлөрдү түзүүгө болот:
- Бир барактуу тиркемелер.
- Интернет-дүкөндөр.
- Жеке кабинеттер.
- Администратор панелдери.
- Билим берүү платформалары.

Мисал:

```jsx
function Welcome() {
    return <h1>LevelUp'ка кош келиңиз!</h1>;
}

export default Welcome;
```

React сайтты өз алдынча компоненттерге бөлүүгө жана аларды кайра колдонууга мүмкүндүк берет.

**Корутунду:** React заманбап жана масштабдуу веб-тиркемелерди түзүүгө жардам берет.

<!-- q:react-component -->
Компонент — сайттын ар кайсы жеринде колдонула турган интерфейстин өзүнчө бөлүгү.

Мисалы:
- Header — сайттын баш жагы.
- Footer — сайттын төмөнкү бөлүгү.
- Button — баскыч.
- CourseCard — курстун карточкасы.

Мисал:

```jsx
function CourseCard() {
    return (
        <div>
            <h2>Жаңы баштагандар үчүн HTML</h2>
            <p>HTML негиздерин үйрөнүңүз.</p>
            <button>Окууну баштоо</button>
        </div>
    );
}

export default CourseCard;
```

**Корутунду:** Компоненттер долбоордун ыңгайлуу түзүмүн түзүүгө жана кодду кайра колдонууга жардам берет.

<!-- q:vite-what -->
Vite — Frontend-тиркемелерди иштеп чыгуу үчүн заманбап курал.

Ал төмөнкүлөргө жардам берет:
- Долбоорду тез иштетүү.
- JavaScript жана CSS файлдарын иштетүү.
- Иштеп чыгуу учурунда баракты жаңыртуу.
- Production-жыйнакты түзүү.

Долбоорду түзүү:

```bash
npm create vite@latest my-project
```

Долбоорду иштетүү:

```bash
cd my-project
npm install
npm run dev
```

**Корутунду:** Vite заманбап веб-сайттарды иштеп чыгуу процессин тездетет.

<!-- q:git-github -->
Git — коддогу өзгөрүүлөрдү сактаган версияларды башкаруу системасы.

GitHub — Git-репозиторийлерди сактоо жана биргелешип иштеп чыгуу үчүн онлайн-платформа.

Git'тин негизги буйруктары:

```bash
git init
git add .
git commit -m "First commit"
git push
```

Git өзгөрүүлөрдү көзөмөлдөөгө, мурунку версияларга кайтууга жана командада иштөөгө жардам берет.

**Корутунду:** Git жана GitHub — заманбап Frontend-иштеп чыгуучунун маанилүү куралдары.

<!-- q:ai-what -->
Жасалма интеллект (ЖИ) — компьютердик системаларга адатта адамдын акылын талап кылган тапшырмаларды аткарууга мүмкүндүк берген технологиялар.

Колдонуу мисалдары:
- Сүрөттөрдү таануу.
- Үн жардамчылары.
- Текстти которуу.
- Сүрөттөрдү генерациялоо.
- Маалыматтарды талдоо.
- Билим берүүчү жардамчылар.

Мисалы, LevelUp'тын ЖИ-жардамчысы окуучуларга программалоо боюнча түшүндүрмөлөрдү алууга жардам берет.

**Корутунду:** Жасалма интеллект тапшырмаларды автоматташтырууга жана жаңы технологиялык чечимдерди түзүүгө жардам берет.

<!-- q:algorithm -->
Алгоритм — белгилүү бир маселени чечүү үчүн так аракеттердин ырааттуулугу.

Мисалы, эки санды кошуу алгоритми:

1. Биринчи санды алуу.
2. Экинчи санды алуу.
3. Сандарды кошуу.
4. Натыйжаны көрсөтүү.

JavaScript'теги мисал:

```javascript
let a = 10;
let b = 20;

let result = a + b;

console.log(result);
```

Натыйжа: 30.

**Корутунду:** Алгоритмдер программалоонун негизи болуп саналат жана маселелерди туура чечүүгө жардам берет.

<!-- q:frontend -->
Frontend-иштеп чыгуу — веб-сайттын колдонуучу түздөн-түз иштеше турган көрүнгөн жана интерактивдүү бөлүгүн түзүү.

Негизги технологиялар:
- HTML — түзүм.
- CSS — дизайн.
- JavaScript — функционалдуулук.
- React — интерфейстерди түзүү.

Frontend-иштеп чыгуучу төмөнкүлөр үчүн жооп берет:
- Барактардын дизайны.
- Адаптивдүүлүк.
- Навигация.
- Формалар жана баскычтар.
- Колдонуучунун сайт менен өз ара аракети.

**Корутунду:** Frontend-иштеп чыгуучу сайтка келген колдонуучулар пайдалана турган интерфейсти түзөт.

<!-- q:first-site -->
Биринчи сайтты түзүү үчүн бир нече кадамдан өтүү керек.

**1-кадам.** Долбоордун папкасын түзүү.

**2-кадам.** index.html файлын түзүү.

**3-кадам.** HTML белгилөөсүн кошуу.

**4-кадам.** style.css файлын түзүү.

**5-кадам.** CSS аркылуу сайтты жасалгалоо.

**6-кадам.** Интерактивдүүлүк үчүн JavaScript кошуу.

Жөнөкөй сайттын мисалы:

```html
<!DOCTYPE html>
<html lang="ky">
<head>
    <meta charset="UTF-8">
    <title>Менин сайтым</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Менин биринчи сайтым</h1>
    <p>Мен программалоону үйрөнүп жатам!</p>
    <button onclick="alert('Салам!')">
        Мени бас
    </button>
</body>
</html>
```

**Корутунду:** Жөнөкөй долбоорлордон баштап, акырындык менен жаңы функцияларды кошуп барыңыз.

<!-- q:start-programming -->
Эгер сиз жаңы баштаган программист болсоңуз, технологияларды ырааттуу үйрөнүү сунушталат.

**Биринчи этап — HTML:**
Веб-барактардын түзүмүн, аталыштарды, шилтемелерди, сүрөттөрдү жана формаларды үйрөнүңүз.

**Экинчи этап — CSS:**
Барактарды жасалгалоону, Flexbox, Grid жана адаптивдүү дизайн менен иштөөнү үйрөнүңүз.

**Үчүнчү этап — JavaScript:**
Өзгөрмөлөрдү, шарттарды, циклдерди, функцияларды, массивдерди жана объекттерди үйрөнүңүз.

**Төртүнчү этап — React:**
Компоненттерди, Props, State, Hooks жана маршрутизацияны үйрөнүңүз.

**Бешинчи этап — Git жана GitHub:**
Долбоорлорду сактоону жана кодду жарыялоону үйрөнүңүз.

**Алтынчы этап — Практика:**
Өз сайттарыңызды, портфолиоңузду жана тиркемелериңизди түзүңүз.

**Корутунду:** Эң негизгиси — үзгүлтүксүз машыгуу, долбоорлорду түзүү жана билим деңгээлин акырындык менен жогорулатуу.
