<!-- q:html-what -->
HTML (HyperText Markup Language) — это язык гипертекстовой разметки, который используется для создания структуры веб-страниц.

С помощью HTML можно добавлять:
- Заголовки.
- Текст.
- Изображения.
- Ссылки.
- Кнопки.
- Формы.

Пример:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Мой первый сайт</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый сайт.</p>
</body>
</html>
```

**Вывод:** HTML создаёт основу и структуру любого веб-сайта.

<!-- q:css-what -->
CSS (Cascading Style Sheets) — язык стилей, который отвечает за внешний вид веб-страниц.

С помощью CSS можно изменять:
- Цвет текста и фона.
- Размер шрифта.
- Расположение элементов.
- Размеры блоков.
- Анимации.
- Адаптивность сайта.

Пример:

```css
h1 {
    color: green;
    font-size: 32px;
    text-align: center;
}

body {
    background-color: #f0fff5;
}
```

**Вывод:** HTML создаёт структуру, а CSS делает сайт красивым и удобным.

<!-- q:html-vs-css -->
HTML и CSS выполняют разные задачи, но работают вместе.

HTML отвечает за структуру сайта, CSS — за его оформление.

Пример HTML:

```html
<h1>Добро пожаловать!</h1>
```

Пример CSS:

```css
h1 {
    color: blue;
    font-size: 30px;
}
```

HTML создаёт заголовок, а CSS задаёт ему синий цвет и размер.

**Вывод:** Для создания полноценного сайта важно изучать оба языка.

<!-- q:js-what -->
JavaScript — язык программирования, который добавляет интерактивность веб-сайтам.

Он позволяет:
- Создавать работающие кнопки.
- Проверять формы.
- Создавать калькуляторы.
- Изменять содержимое страницы.
- Разрабатывать игры.
- Работать с API.

Пример:

```javascript
function sayHello() {
    alert("Привет! Добро пожаловать!");
}
```

```html
<button onclick="sayHello()">Нажми меня</button>
```

При нажатии на кнопку появляется сообщение.

**Вывод:** JavaScript делает сайты динамичными и интерактивными.

<!-- q:js-variable -->
Переменная — это именованное место для хранения данных.

В JavaScript используются три основных способа объявления переменных: let, const и var.

Пример:

```javascript
let name = "Akinai";
const age = 20;

console.log(name);
console.log(age);
```

- let — значение переменной можно изменить.
- const — нельзя повторно присвоить другое значение.
- var — старый способ объявления переменных.

**Вывод:** Переменные позволяют хранить и использовать информацию в программе.

<!-- q:js-function -->
Функция — это блок кода, который выполняет определённую задачу. Её можно вызывать несколько раз.

Пример:

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(5, 3));
```

Результат:

```javascript
8
```

Функции помогают:
- Не повторять одинаковый код.
- Разделять программу на части.
- Упрощать разработку.
- Повторно использовать готовую логику.

**Вывод:** Функции делают программный код удобным и организованным.

<!-- q:react-what -->
React — JavaScript-библиотека для создания пользовательских интерфейсов.

Она позволяет создавать:
- Одностраничные приложения.
- Интернет-магазины.
- Личные кабинеты.
- Панели администратора.
- Образовательные платформы.

Пример:

```jsx
function Welcome() {
    return <h1>Добро пожаловать в LevelUp!</h1>;
}

export default Welcome;
```

React позволяет разбивать сайт на независимые компоненты и повторно использовать их.

**Вывод:** React помогает создавать современные и масштабируемые веб-приложения.

<!-- q:react-component -->
Компонент — это отдельная часть интерфейса, которую можно использовать в разных местах сайта.

Например:
- Header — шапка сайта.
- Footer — нижняя часть.
- Button — кнопка.
- CourseCard — карточка курса.

Пример:

```jsx
function CourseCard() {
    return (
        <div>
            <h2>HTML для начинающих</h2>
            <p>Изучите основы HTML.</p>
            <button>Начать обучение</button>
        </div>
    );
}

export default CourseCard;
```

**Вывод:** Компоненты помогают создавать удобную структуру проекта и повторно использовать код.

<!-- q:vite-what -->
Vite — современный инструмент для разработки Frontend-приложений.

Он помогает:
- Быстро запускать проект.
- Обрабатывать JavaScript и CSS.
- Обновлять страницу во время разработки.
- Создавать production-сборку.

Создание проекта:

```bash
npm create vite@latest my-project
```

Запуск проекта:

```bash
cd my-project
npm install
npm run dev
```

**Вывод:** Vite ускоряет процесс разработки современных веб-сайтов.

<!-- q:git-github -->
Git — система контроля версий, которая сохраняет изменения в коде.

GitHub — онлайн-платформа для хранения Git-репозиториев и совместной разработки.

Основные команды Git:

```bash
git init
git add .
git commit -m "First commit"
git push
```

Git помогает отслеживать изменения, возвращаться к предыдущим версиям и работать в команде.

**Вывод:** Git и GitHub являются важными инструментами современного Frontend-разработчика.

<!-- q:ai-what -->
Искусственный интеллект (ИИ) — это технологии, позволяющие компьютерным системам выполнять задачи, для которых обычно требуется человеческий интеллект.

Примеры применения:
- Распознавание изображений.
- Голосовые помощники.
- Перевод текста.
- Генерация изображений.
- Анализ данных.
- Образовательные помощники.

Например, ИИ-ассистент LevelUp помогает учащимся получать объяснения по программированию.

**Вывод:** Искусственный интеллект помогает автоматизировать задачи и создавать новые технологические решения.

<!-- q:algorithm -->
Алгоритм — это последовательность чётких действий для решения определённой задачи.

Например, алгоритм сложения двух чисел:

1. Получить первое число.
2. Получить второе число.
3. Сложить числа.
4. Показать результат.

Пример на JavaScript:

```javascript
let a = 10;
let b = 20;

let result = a + b;

console.log(result);
```

Результат: 30.

**Вывод:** Алгоритмы являются основой программирования и помогают правильно решать задачи.

<!-- q:frontend -->
Frontend-разработка — это создание видимой и интерактивной части веб-сайта, с которой непосредственно взаимодействует пользователь.

Основные технологии:
- HTML — структура.
- CSS — дизайн.
- JavaScript — функциональность.
- React — создание интерфейсов.

Frontend-разработчик отвечает за:
- Дизайн страниц.
- Адаптивность.
- Навигацию.
- Формы и кнопки.
- Взаимодействие пользователя с сайтом.

**Вывод:** Frontend-разработчик создаёт интерфейс, которым пользуются посетители сайта.

<!-- q:first-site -->
Для создания первого сайта нужно пройти несколько этапов.

**Шаг 1.** Создать папку проекта.

**Шаг 2.** Создать файл index.html.

**Шаг 3.** Добавить HTML-разметку.

**Шаг 4.** Создать файл style.css.

**Шаг 5.** Оформить сайт с помощью CSS.

**Шаг 6.** Добавить JavaScript для интерактивности.

Пример простого сайта:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Мой первый сайт</h1>
    <p>Я изучаю программирование!</p>
    <button onclick="alert('Привет!')">
        Нажми меня
    </button>
</body>
</html>
```

**Вывод:** Начинай с простых проектов, постепенно добавляя новые функции.

<!-- q:start-programming -->
Если ты начинающий программист, рекомендуется изучать технологии последовательно.

**Первый этап — HTML:**
Изучи структуру веб-страниц, заголовки, ссылки, изображения и формы.

**Второй этап — CSS:**
Научись оформлять страницы, работать с Flexbox, Grid и адаптивным дизайном.

**Третий этап — JavaScript:**
Изучи переменные, условия, циклы, функции, массивы и объекты.

**Четвёртый этап — React:**
Изучи компоненты, Props, State, Hooks и маршрутизацию.

**Пятый этап — Git и GitHub:**
Научись сохранять проекты и публиковать код.

**Шестой этап — Практика:**
Создавай собственные сайты, портфолио и приложения.

**Вывод:** Главное — регулярно практиковаться, создавать проекты и постепенно повышать уровень знаний.
